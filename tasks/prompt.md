# Claude Code 実装指示プロンプト

## あなたの役割

PHPを学習中の学生の実装をサポートするエンジニアとして動いてください。
添付の`PRD.md`をベースに、メール認証付き会員登録システムを実装してください。

---

## 実装の前提条件

- 実行環境：XAMPP（ローカル開発）
- PHPとHTMLは同じ`.php`ファイルに共存させる
- CSSとJSは別ファイルに分離する（`css/style.css`、`js/main.js`）
- Tailwind CSS はCDN版を使用する（ビルド不要）
- jQueryはCDN版を使用する
- データ保存はCSV（MySQLは使わない）
- ページ間のデータ引き回しは`$_SESSION`を使う（`<input type="hidden">`は使わない）
- メール送信はPHPの`mail()`関数を使用（Mailtrap経由を想定）

---

## 実装の進め方

**必ずファイルを1つずつ実装し、各ファイルが完成したら次に進んでください。**
いきなり全ファイルを一括生成しないこと。

実装順序：
1. `index.php`（入力フォーム）
2. `confirm.php`（確認画面）
3. `send_mail.php`（メール送信＋CSV保存）
4. `verify.php`（トークン照合・本登録）
5. `complete.php`（登録完了）
6. `list.php`（ユーザー一覧・管理用）
7. `css/style.css`（共通スタイル補足）
8. `js/main.js`（バリデーション）

---

## コードの書き方ルール

### PHP
- 処理の意図がわかるように**日本語コメントを必ず書く**
- `$_POST`を受け取ったら必ず`htmlspecialchars()`でXSS対策をする
- ページ間のデータ引き回しは`$_SESSION`を使う
  - セッション開始：各ファイルの先頭で`session_start()`を呼ぶ
  - 保存：`$_SESSION['key'] = 値`
  - 取り出し：`$変数 = $_SESSION['key']`
  - 破棄：CSV保存・メール送信完了後に`session_destroy()`
- CSVの読み書きは`fopen` / `fwrite` / `flock` / `fclose`を使う
- トークン生成は`bin2hex(random_bytes(32))`を使う

### HTML
- Tailwind CSSのユーティリティクラスでスタイリングする
- フォームのinputには適切な`type`と`name`属性を必ずつける
- `<input type="hidden">`は使わない（セッションで代替）

### JavaScript / jQuery
- フォーム送信前にjQueryでバリデーションを行う
- バリデーション対象：名前（必須）、メール（必須・形式）、パスワード（必須・半角英数8文字以上）
- エラーメッセージはinputの直下に表示する

## 各ファイルの完成基準

| ファイル | 完成基準 |
|---------|---------|
| `index.php` | フォームが表示され、confirm.phpにPOSTで送信できる |
| `confirm.php` | セッションに値が保存され、入力内容が画面に表示される。戻る／登録するボタンが機能する |
| `send_mail.php` | セッションから値を取り出してCSVに保存、認証メールが送信され、セッションが破棄される |
| `verify.php` | トークンが照合され、statusが`active`に更新される |
| `complete.php` | 登録完了メッセージが表示される |
| `list.php` | CSVの内容が一覧表示される |
| `css/style.css` | Tailwindで対応できない細かいスタイルが定義されている |
| `js/main.js` | 全入力項目のバリデーションが動作する |

---

## 注意事項

- スコープ外の機能（ログイン・パスワードハッシュ化・トークン有効期限）は**実装しない**
- 実装中に不明点があれば実装を止めて質問すること
- 各ファイルを作成したら、動作確認のポイントも一緒に教えること
