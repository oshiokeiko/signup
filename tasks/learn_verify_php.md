# verify.php の学びメモ

`verify.php` は、**メールアドレスが本物か確認して、本登録を完了させる**ページ。
会員登録の「最後の関門」。メール内の認証リンクをクリックすると、このページが動く。

---

## 1. 役割（一言で）

仮登録（pending）の人を、**メール認証によって本登録（active）に格上げ**する受付係。

---

## 2. なぜ必要？

入力されたメールアドレスが「本当に使える本人のもの」かは、入力時点ではわからない。
→ アドレス宛に**合言葉つきリンク**を送り、**クリックできた＝本物**と確認する。

---

## 3. 動きの流れ

| 順 | やること | 行 |
|---|---|---|
| ① | リンクの合言葉（token）を受け取る | [7](../verify.php#L7) |
| ② | CSVから同じ token を持つ人を探す | [40-51](../verify.php#L40-L51) |
| ③ | 見つかれば status を `pending`→`active` に書き換え | [47](../verify.php#L47) |
| ④ | 成功なら完了画面 complete.php へ移動 | [74-77](../verify.php#L74-L77) |
| ⑤ | 合言葉が無い／不一致ならエラー画面を表示 | [67-68](../verify.php#L67-L68) |

---

## 4. 合言葉（トークン）とは

- 登録時に作られる、**推測されにくい長いランダム文字列**（send_mail.php で生成）
- メールを受け取った本人しか本登録できない → **なりすまし防止**
- 照合は `hash_equals()` を使う（安全な比較）[45](../verify.php#L45)

---

## 5. 安全の工夫

- **`flock`（ロック）** … 書き換え中に他の処理が割り込まないようにする [31](../verify.php#L31)
- **`hash_equals`** … 合言葉の比較を安全に行う（タイミング攻撃対策）[45](../verify.php#L45)
- **CSVを全部読み込み → 該当行だけ書き換え → 丸ごと上書き** という手順 [56-60](../verify.php#L56-L60)

---

## 6. 3つのファイルの関係

| ファイル | 役割 |
|---|---|
| send_mail.php | 合言葉つきの確認メールを**送る** |
| **verify.php** | リンクの合言葉を**照合して本登録する** |
| complete.php | 「登録できました！」と**完了を知らせる** |

→ list.php で status が `pending`→`active` に変わるのは、verify.php が働いた証拠。

---

## 7. たとえ

- フォーム入力 … 入会の申し込み（仮登録 = pending）
- メールのリンク … 本人確認用の引換券
- **verify.php** … 引換券を照合する受付係。本物なら本会員（active）にする

---

## 8. 用語のかんたん辞書

- **token（トークン）** … 本人確認用の合言葉（ランダムな文字列）
- **status** … 登録の状態。pending=仮登録 / active=本登録
- **`$_GET`** … URL（?token=...）から値を受け取る入れ物
- **flock** … ファイルに鍵をかけて、同時操作の事故を防ぐ
- **hash_equals** … 文字列を安全に比較する関数
