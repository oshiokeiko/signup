# FileZilla でレンタルサーバーに公開する（学びメモ）

作ったシステムを、自分のPC（XAMPP）から **さくらのレンタルサーバー** に
アップして、インターネットに公開するまでの手順とつまずきのまとめ。

---

## 1. FileZilla とは（一言で）

- **自分のPCのファイルを、サーバーに手で運ぶための道具**（FTPソフト）
- 画面は左右に分かれていて：
  - **左 = 自分のPC（ローカル）**
  - **右 = サーバー（リモート）**
- 左から右へ**ドラッグ＆ドロップ**するだけでアップロードできる

---

## 2. ぜんたいの流れ

```
自分のPC（XAMPP htdocs）
   │  FileZilla でドラッグ＆ドロップ
   ▼
さくらサーバーの公開フォルダ（/home/アカウント名/www）
   │
   ▼
ブラウザで http://アカウント名.sakura.ne.jp/フォルダ名/ で見られる
```

---

## 3. どこに置く？（公開フォルダ）

- さくらの公開フォルダは **`/home/アカウント名/www`**（この中に置いたものが公開される）
- そのまま全部バラまくと他のサイトと混ざるので、**`signup` などフォルダを作ってその中に入れる**
- 結果のURL：`http://アカウント名.sakura.ne.jp/signup/index.php`

⚠️ 注意：`www` の中にさらに `www` がある等、紛らわしいフォルダに入れないこと。

---

## 4. 何を上げる？何を上げない？

| 上げる ✅ | 上げない ❌ |
|---|---|
| 各PHPファイル（index, confirm, send_mail, verify, complete, list） | `.git`（Git管理用の隠しフォルダ） |
| `PHPMailer` / `css` / `js` フォルダ | `.gitignore`（GitHub用の設定） |
| **`mail_config.php`**（メール送信に必要！） | `tasks`（学習メモ） |
| `data` フォルダ（中の `.htaccess` ごと） | `README.md`（任意） |

### ポイント：GitHub と サーバーは「真逆」
- **GitHub** … 公開の場 → 秘密情報（mail_config.php）は **上げない**
- **サーバー** … 動かす場所 → 秘密情報が **必要**なので **上げる**
- `.gitignore` は「GitHubに送らない」設定なので、**FileZillaの手動アップには関係ない**（自分で運ぶ）

## 5. つまずき① 500エラー（このページは動作していません）

「登録する」を押すと真っ暗（HTTP ERROR 500）になった。

### 500 とは
- **プログラムが途中でエラーを起こして止まった**サイン
- 中身が隠れているので、原因を「見える化」する必要がある

### 調査のしかた（安全な方法）
- エラーを**画面に出すのは危険**（他人に見られる）
- → **画面には出さず、外から見えない `data/debug.log` に記録**させた
  - `data` は `.htaccess` で保護済みなので、ログも他人に見えない
- 記録された中身を FileZilla でダウンロードして確認 → 原因判明
- ※ 調査が終わったら、仕掛けた行とログは**必ず削除**する

---

## 6. つまずき② 本当の原因＝日本語コメントの文字化け

- `debug.log` に出たエラー：`mail_config.php on line 10 で syntax error`
- **ローカルのファイルは正常**なのに、**サーバー上だけ壊れていた**
- 原因：**日本語（マルチバイト文字）のコメント**が、転送やサーバー環境で崩れて文法エラーに
- バイナリ転送に変えても直らなかった

### 対処
- `mail_config.php` の**コメントを英語・記号だけ（ASCII）に書き換え**た
- 接続情報（値）はそのまま → 上げ直したら **動いた！**

> 教訓：サーバーに上げる設定ファイルは、コメントを日本語にしない方が安全。

---

## 7. 覚えておくと安心なこと

- **PHPのバージョン**：さくらの管理画面で確認できる（今回は 8.2 で新しく、問題なし）
  - 古いPHPだと新しい書き方が動かず500になることがある
- **data フォルダの書き込み権限**：登録データ(CSV)を書き込むので、書けないとエラー
  - さくらは通常そのままでも書ける（ローカルXAMPPの `chmod 777` 問題とは別）
- **認証リンクのURL**は、コードがアクセス中の住所を自動で読むので、
  localhost → サーバーへ移しても**手直し不要**

---

## 8. 用語のかんたん辞書

- **FTP / FileZilla** … PCとサーバーの間でファイルを運ぶ仕組み・道具
- **ローカル / リモート** … 自分のPC側 / サーバー側
- **公開フォルダ（www）** … ここに置いたものがインターネットに公開される
- **500エラー** … サーバー側でプログラムが止まったサイン
- **バイナリ転送** … ファイルを1バイトも変えずにそのまま運ぶ転送方法
- **マルチバイト文字** … 日本語など、1文字に複数バイト使う文字（崩れやすい）
- **ASCII** … 英数字・記号など、崩れにくい基本的な文字
