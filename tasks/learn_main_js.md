# main.js の学びメモ

`js/main.js` は、会員登録フォーム（index.php）の**入力チェック（バリデーション）**を行うファイルです。
「送信する前に、入力ミスをその場で教えてあげる」のが役割です。

---

## 1. ぜんたいの仕組み（一言で）

入力欄（お名前・メール・パスワード）をチェックして、
- 問題あり → 赤く強調し、エラー文章を表示する
- 問題なし → エラー表示を消す

これを **「欄から離れたとき」** と **「送信したとき」** の2つのタイミングで行います。

---

## 2. 登場する4つの関数（係）

| 関数（係の名前） | やること |
|---|---|
| `showError` | エラーを**表示する**（赤くする＋文章を出す） |
| `clearError` | エラーを**消す**（後始末） |
| `validateField` | **1つの欄だけ**を検査して、合格/不合格を返す |
| （送信時の処理） | **全部の欄**をまとめて検査し、ダメなら送信を止める |

---

## 3. チェックのルール

| 欄 | ルール |
|---|---|
| お名前 | 空っぽはダメ（必須） |
| メール | 必須 ＋ メールの形（@とドメイン）が正しいか |
| パスワード | 必須 ＋ 半角英数字8文字以上 |

---

## 4. 2つのタイミング（二段構え）

- **欄から離れたとき（blur）** … その1つだけをチェック（こまめに）
- **送信ボタンのとき（submit）** … 3つ全部まとめてチェック（最終確認）
  - 1つでもダメなら `preventDefault()` で送信を止める
  - `&&` を使わず全部見るので、**複数のエラーをまとめて表示**できる

---

## 5. 覚えておきたいポイント

- **`name`** … 「この欄は何の欄か」の目印（name / email / password）。どの検査をするか決めるのに使う。
- **`value`** … 実際に入力された文字。`.trim()` で前後の空白を取り除く（スペースだけの入力を防ぐ）。
- **エラーは最初は出ていない** … 表示欄は最初 `hidden`（隠す）状態。`clearError` は「前に出したエラーを消す」後始末。
- **`$(this)`** … 「いま操作した、まさにその欄」を指す。

---

## 6. 用語のかんたん辞書

- **バリデーション** … 入力チェックのこと
- **blur（ブラー）** … 入力欄から離れた瞬間
- **submit（サブミット）** … フォームを送信すること
- **preventDefault** … 「いつもの動き（＝送信）を止める」命令
- **jQuery（`$`記号）** … 画面の部品を簡単に操作するための道具
